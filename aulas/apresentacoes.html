Apresentações.

Antes de escrever código, precisamos compreender a linguagem que estamos utilizando, suas propostas e os mecanismos que fazem Rust funcionar.

01. O que é Rust?

Rust é uma linguagem de programação de sistemas, compilada e multiparadigma. Ela foi projetada para oferecer alto desempenho e segurança de memória.

Diferentemente de linguagens que dependem de um coletor de lixo tradicional, Rust utiliza um conjunto de regras conhecido como Ownership para controlar a memória.

02. Por que Rust foi criada?

Muitos sistemas precisam de controle direto sobre memória e recursos computacionais. Linguagens como C e C++ oferecem esse controle, mas permitem erros difíceis de detectar.

Rust procura combinar controle de baixo nível com garantias de segurança verificadas durante a compilação.

Seus principais objetivos incluem:

• Desempenho próximo ao de linguagens de baixo nível.
• Segurança de memória em código Rust seguro.
• Concorrência com garantias de segurança.
• Controle explícito sobre recursos.

03. Linguagem compilada

Rust é uma linguagem compilada. O código-fonte passa por um processo de compilação antes de ser executado como um programa nativo.

Podemos observar esse processo no terminal:

zoth@rust: ~ 
zoth@rust:~$ rustc main.rs

Compilação concluída.
Executável gerado: main

zoth@rust:~$ ./main

Programa executado.

O compilador verifica o código e identifica diversos problemas antes de produzir o executável.

04. O compilador Rust

O compilador oficial da linguagem é chamado rustc.

Ele transforma o código Rust em código executável para a plataforma de destino. Também verifica regras importantes da linguagem, incluindo tipos, ownership e empréstimos.

zoth@rust: ~ 
zoth@rust:~$ rustc main.rs

Esse comando solicita ao compilador que compile o arquivo main.rs.

05. Cargo

Cargo é o gerenciador de pacotes e ferramenta de construção oficial do ecossistema Rust.

Ele permite criar projetos, compilar programas, executar testes e administrar dependências.

zoth@rust: ~/Projetos 
zoth@rust:~/Projetos$ cargo new meu_projeto

Creating binary (application) `meu_projeto` package

zoth@rust:~/Projetos$ cd meu_projeto

zoth@rust:~/Projetos/meu_projeto$ cargo run

Compiling meu_projeto v0.1.0
Finished dev profile
Running target/debug/meu_projeto

O Cargo automatiza várias tarefas que, de outra forma, precisariam ser realizadas manualmente.

06. Ownership

Ownership é um dos conceitos centrais de Rust. Ele define quem é responsável por um valor e controla por quanto tempo esse valor permanece válido.

Esse sistema trabalha em conjunto com empréstimos (borrowing) e tempos de vida (lifetimes).

Importante: ownership não é um coletor de lixo. É um conjunto de regras aplicado pelo compilador para controlar a memória.

07. Onde Rust é utilizada?

Rust pode ser utilizada em diferentes áreas da computação, principalmente onde desempenho e controle de recursos são importantes.

• Ferramentas de sistema.
• Sistemas operacionais.
• Aplicações de linha de comando.
• Desenvolvimento de servidores.
• Sistemas embarcados.
• Componentes de infraestrutura.

08. Nosso objetivo

O objetivo deste estudo é compreender Rust desde seus fundamentos até o desenvolvimento de aplicações reais.

Não vamos apenas memorizar sintaxe. Vamos estudar tipos, memória, lógica, estruturas de dados, compilação e interação com o sistema operacional.
